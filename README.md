# NYSI-Capstone-Group-INSMS
## Creating venv to run ocr_service
### Step 1: Create folder to store your venv and change your terminal directory to be that folder
### Step 2: create the venv by running "python -m venv venv" on your terminal
### Step 3: Install the following packages using pip install:
            - FastAPI
            - uvicorn
            - python-multipart
            - paddleocr
            - paddlepaddle
